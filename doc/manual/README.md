# Phosphor Deck manual

One source for everything: `phosphor help TOPIC` shows these pages in the
deck, and `phosphor docs` builds AGENTS.md from them for AI assistants. Edit
the page here; never a copy.

| topic | what it covers |
|---|---|
| concepts | the deck, the brain, the fleet, faces |
| install | from nothing to inside the deck, and how to remove it |
| patterns | which shape to pick, growing a deck, moving it to a new brain |
| profile | every setting in ~/.config/phosphor/deck.toml, and your own apps |
| commands | every `phosphor` command |
| keys | keys inside the deck, and what happens when a program ends |
| phones | screens: phones, other computers, anything with ssh |
| workspaces | a tab per idea: its folder, its assistants, its notebook |
| mentions | the read-only chat feed and "prepare notes" |
| web | the deck in a browser, only inside your tailnet |
| tunnels | keeping your ssh config's LocalForward tunnels up |
| clipboard | one clipboard for every screen |
| privacy | what stays where, and checking a fork before you push |
| troubleshooting | when something doesn't work |
